## 🚀 Visión General

El **SGE** nace de la necesidad de optimizar los procesos administrativos (inscripciones, gestión de matrícula y reportes) reduciendo la carga manual y eliminando la dependencia de servidores externos. Su interfaz, diseñada bajo principios de *Glassmorphism*, ofrece una experiencia fluida e intuitiva para el personal docente y administrativo.

## ✨ Características Principales

*   **Experiencia de Usuario Premium:** Interfaz reactiva, moderna y amable, diseñada para reducir la fatiga visual y mejorar la productividad.
*   **Arquitectura Offline-First:** Toda la potencia del sistema reside en el dispositivo local. Base de datos encriptada y gestión de archivos autónoma; no requiere internet para funcionar.
*   **Wizard de Inscripción Inteligente:** Flujo guiado paso a paso para el registro de estudiantes, con detección automática de duplicados para mantener la integridad de la data.
*   **Centro de Impresión Nativo:** Generación de planillas, constancias y listados oficiales con formato A4 exacto, directos a la impresora del sistema.
*   **Acceso Móvil Híbrido:** Incluye un servidor local integrado que permite a otros dispositivos (celulares/tablets) conectarse vía WiFi mediante QR para consultas y toma de asistencia, sin necesidad de internet.
*   **Seguridad y Privacidad:** Datos protegidos localmente. Hashing de credenciales y sanitización de consultas para prevenir vulnerabilidades comunes.

## 🛠️ Stack Tecnológico

Desarrollado utilizando tecnologías de vanguardia para garantizar rendimiento y mantenibilidad:

*   **Core:** Electron + React (Vite)
*   **UI/UX:** Tailwind CSS + Framer Motion
*   **Almacenamiento:** Base de datos NoSQL local (persistencia segura)
*   **Seguridad:** IPC Bridge controlado y validación de esquemas estricta

## 🔒 Privacidad y Uso

Este software es una herramienta de gestión interna y privada.
*   No recopila telemetría externa.
*   No expone datos a la nube pública.
*   El control de los datos es 100% de la institución.
